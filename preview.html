BeyondWords Player Preview

A clean page for testing the player against any project. Use the Content section in the panel to fetch production content, or add query params like ?projectId=…&contentId=…&playerStyle=default directly to the URL. Add &advanced=true to expand every setting.

This page has no article markers, so in-article highlighting and click-to-play-a-paragraph settings (highlightColor, wordHighlight*, highlightSections, clickableSections, segmentWidget*) do nothing here — use index.html for those. Settings that belong to a surface only apply while it is on screen: skips, speed and playerTitle need playback, the queue needs playlist content, widget* needs the docked widget, and video* needs video: true.
