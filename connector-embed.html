A real standalone embed.

This page loads /dist/connector.js as a normal script. No player, agent SDK, separate stylesheet, or font download is needed.

The buttons are real links, not intercepted preview clicks. For this local example, they open the widget design preview. Supply your own connection-page URL when embedding.

Build the standalone files with ./bin/build_connector, then reload this page.

Embed code

Place the mounting element before the scripts. Replace both URLs with your hosted widget script and your connection page.

<div id="connector"></div>
<script src="/dist/connector.js"></script>
<script>
  const connector = new BeyondWords.Connector({
    target: "#connector",
    connectUrl: "https://publisher.example/connect/claude",
    provider: "claude",
    theme: "auto"
  });
</script>

Update or remove it

connector.update({ theme: "dark", label: "Explore our reporting" });
connector.destroy();
